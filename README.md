# 🌐 Guilherme Scavassa — Portfolio

Portfolio pessoal desenvolvido em HTML, CSS e JavaScript puro, com suporte a múltiplos idiomas (PT, EN, ES) e design minimalista focado em Cybersecurity, Data e IA.

🔗 **[gui-scavassa.github.io](https://gui-scavassa.github.io)**

---

## ✨ Funcionalidades

- **Multilíngue** — alternância instantânea entre Português, Inglês e Espanhol
- **Design responsivo** — adaptado para desktop, tablet e mobile
- **Cursor personalizado** — com efeito de anel animado (desativado em touch)
- **Scroll reveal** — animações suaves ao rolar a página
- **Nav dinâmica** — destaque automático da seção ativa
- **SEO otimizado** — meta tags, Open Graph e JSON-LD estruturado
- **Acessibilidade** — atributos `aria-label`, `alt` descritivos e semântica correta

## 🌍 Sistema de Tradução

O portfólio usa um sistema de i18n próprio, baseado em atributos `data-i18n` e um objeto de traduções em JavaScript. Ao clicar nos botões **PT / EN / ES** no nav, todo o conteúdo é atualizado via `innerHTML` sem recarregar a página.

```javascript
// Exemplo de uso
<p data-i18n="hero_desc">Texto em português...</p>

// Troca de idioma
setLang('en'); // atualiza todos os elementos com data-i18n
```
